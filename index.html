CryptoIn

Real-time crypto tracker with instant conversion

My role: Full-Stack Developer & Founder

A client needed real-time crypto tracking with instant conversion between coins, without juggling multiple sites. I built CryptoIn: a Flask backend pulling live data from the CoinGecko API, paired with a hand-crafted HTML5/CSS3 frontend featuring glassmorphism and responsive grids. Users see live prices, market caps, and 24h trends, then convert any coin to another instantly. I containerized and hosted the app using Docker for reliable, consistent deployment.

Tech Stack: Flask (Python) · CoinGecko API · HTML5/CSS3 · Docker

RecipeCore

Recipe discovery app with favorites and PDF export

My role: Full-Stack Developer & Founder

A food blog client needed users to discover recipes fast and save favorites, but had no backend or scalable storage. I built RecipeCore: a React frontend for instant recipe search, a FastAPI backend with secure auth, and PostgreSQL for persistent "Favorites." Users can also export saved recipes as PDFs. Result: a static content site became an interactive product with real-time search and zero data loss.

Tech Stack: React · FastAPI (Python) · PostgreSQL

  • FastAPI

TranslateCorner

Instant translation tool with automatic language detection

My role: Full-Stack Developer & Founder

A client needed a fast way for non-technical users to translate text across languages without picking a source language manually. I built TranslateCorner: a Django backend integrating the Google Cloud Translation API with automatic language detection, plus a clean, responsive HTML/CSS interface. I also set up a CI/CD pipeline for automated testing and friction-free deployment. Result: a frictionless, production-ready tool that removed manual guesswork for global users.

Tech Stack: Django (Python) · Google Cloud Translation API · HTML/CSS · CI/CD
